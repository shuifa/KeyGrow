## 📖 项目简介

**KeyGlow** 专为**屏幕录制、编程教学、设计演示、技术分享与直播**量身打造。参考了 Keystroke Pro 的核心体验与拟物灵感，融合现代化 macOS 设计语言，首要追求：**视觉极度精致、动画丝滑自然、系统性能零负担、核心功能简单克制**。

## 🆕 v0.100 变更摘要

**全面对标 Keystroke Pro v2，配色、几何、动效与显示策略整体重写。**

- **配色改用「材质字典 + 四色槽」。** 七档色相主题整体下线，改为 Keystroke Pro 的物理材料命名体系：浅铝 Aluminium / 象牙白 Ivory / 石墨 Graphite / 深空 Space / 玛瑙灰 Agate Gray / 白垩 Chalk / 中灰 Chromium + 八个手工挑选的高饱和塑料色 + 跟随系统强调色。按键、修饰键、Esc、底板四个色槽彼此独立，任意组合都被允许。
- **材质的两条物理规律写进代码。** 中性材质**上亮下暗**（金属冷感），彩色材质**上暗下亮**（保住饱和度，不读成暗块）；前唇压到 25% 亮度、折角暗部、唇线打亮 22%，全部由基准色派生并受单元测试保护。
- **几何按实测比例重建。** 键帽是 0.97H × 1H 的**竖矩形**（不是正方形），圆角只有 8.6%H，前唇 9.7%H，底板圆角 21%H、内边距 15%H；命名键宽度按真实键盘比例（command 1.5u、escape 1.25u、delete/return 1.75u、space 2u）。
- **两种外形架构：** 独立键帽（Classic，整组共享一块圆角底板）与药丸胶囊（Pill，整组收进一根长条），设置内可切换。
- **排版对齐原版：** 修饰符号在右上、小写标签在右下，两者右边缘对齐；单字符居中放大；方向键只画矢量箭头。
- **显示范围收窄为「特殊键 + 组合键」。** F1–F12、Fn、⌘⌥⌃⇧、方向键、esc、return、delete、tab、space 单按上台；任意含修饰键的组合（⌘S、⌃⇧Tab）上台。**单独输入的字母、数字、标点一律静默**，录屏不会泄漏正在输入的文字。
- **长按驻留（Key Hold）。** 事件掩码加入 `keyUp`：按住不放时键帽持续驻留，松开后才开始计算停留时长；停留时长可调 0.2~5 秒（推荐 1~2 秒）。
- **动效重做：** 按下瞬间轻微放大弹入（spring 0.34s / bounce 0.28），驻留期完全静止，超时后平滑淡出并轻微缩小（0.30s）。
- **锚点改为 8 个。** 3×3 网格去掉正中心（中心留给显示器名称），下线「跟随鼠标光标」；窗口不再使用固定 720×140 画布，直接铺满屏幕可见区域，8 个吸附点全部交给 SwiftUI 对齐，彻底消除「键帽变宽后被画布裁掉」。
- **配置面重排**为「通用 / 外观 / 显示」三页签，与 Keystroke Pro 的 General / Appearance / Displays 一一对应。移除键帽不透明度、键帽托盘开关、同屏数量上限、配置导入导出与外观模式；旧配置项在升级时一次性清理。

## ✨ 核心亮点

### 1. 拟物键帽视觉（Skeuomorphic Keycap）
- **五层材质结构：** 侧壁／前唇 → 折角 → 顶面纵向渐变 → 唇线 → 字符层，逐层对应真实注塑键帽的受光关系；顶面是平的渐变塑料，不做内凹碟面、不加噪点。
- **微立体倒角：** 键帽边缘一圈 1px 顶亮底暗的物理描边，在深色底板上读得出倒角。
- **深度漫反射投影：** 大扩散、低透明度的环境遮蔽软阴影 + 一道极紧的接触影，键帽落在亮色窗口或暗色桌面上都有明确空间层级。
- **原生 SF Symbols：** 修饰键统一用 macOS 原生矢量符号（`command`, `option`, `control`, `shift`），严格遵循 `⌃ ⌥ ⇧ ⌘` 排序规范。
- **矢量无级缩放：** 尺寸滑条 0.7x ~ 2.2x（键帽 43pt ~ 136pt），字符全部矢量渲染，放大到 4K 录制尺寸也不发虚。

### 2. 材质字典 × 四色槽（Material Dictionary & Color Slots）
- **按键 / 修饰键 / Esc / 底板四个色槽彼此独立**，任意组合都被允许——浅修饰键配深字母键这类完整反转同样支持。
- **13 种按键材质 + 4 种底板材质：** 中性材质给出实测的顶面双端色（浅铝 `#F4F4F4 → #B8B8B8`、石墨 `#525252 → #2D2D2D`），彩色材质由单一基准色派生（朱红 `#FC2C32`、钴蓝 `#3A53F5`、靛紫 `#5E39F0`……），另有跟随系统强调色。
- **出厂默认即原版默认：** Key = Aluminium / Modifier = Space / Escape = Accent Color / Border = Agate Gray。
- **字符可读性自动判定：** 白字优先，仅当白字对比度低于 3:1 时翻成深墨字，浅铝与象牙白配深字、深空与钴蓝保白字。

### 3. 「右边进、左边出」流式动效（Spring Physics）
- **入场：** 按下瞬间轻微放大弹入（scale 0.88 → 1 + 位移 + 弹簧），物理阻尼感细腻。
- **驻留：** 长按不放时键帽持续驻留，全程完全静止，不做呼吸或高亮。
- **离场：** 松开后经过停留时长（0.2~5 秒可调）平滑淡出并轻微缩小。
- **连按计数：** 同一按键连续按下时原地显示 `×N` 角标（可关闭）。
- **组合分隔：** 组内键间距 0.17H、组间 0.34H + 两侧各 0.15H 底板留白，连续多个组合不会被读成一长串键帽。

### 4. 8 个智能吸附点
- **3×3 网格去掉正中心**（中心留给显示器名称，与原版一致）：左上 / 顶部居中 / 右上 / 左侧居中 / 右侧居中 / 左下 / 底部居中 / 右下。
- **边距可调：** 8~240pt 滑动条统一控制键帽组与屏幕可见边缘的距离，自动避开菜单栏与程序坞。
- **多显示器自适应：** 键帽出现在鼠标所在的那块屏幕上，按该屏的可见区域计算吸附位置。

### 5. 穿透悬浮窗与极速架构
- **零干扰穿透：** 基于定制 `NSPanel`，配置 `ignoresMouseEvents = true`，鼠标点击与手势 100% 穿透到底层窗口，绝不阻碍用户操作。
- **多桌面与全屏穿透：** `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary]`，虚拟桌面 Spaces 切换及全屏应用时始终悬浮常驻，不抢夺输入焦点。
- **后台纯监听：** 基于 `CGEventTap`（`.listenOnly`）运行于专用后台线程，对日常打字零延迟；内置超时自愈机制；遇密码输入框（Secure Input）自动静默降级保护隐私。

## 🛠️ 技术架构

- **UI & 动效：** 纯原生 SwiftUI 5，结合 `phaseAnimator`、Spring 弹簧物理曲线。
- **窗口管理：** AppKit `NSPanel` + `NSHostingController`（解耦布局约束，杜绝 Auto Layout 递归）。
- **底层监听：** CoreGraphics `CGEventTap` + Carbon 键码映射 + Unicode 字符提取。
- **常驻入口：** 状态栏菜单（`NSStatusItem`）常驻管理，支持一键切换监听、键帽形态、吸附位置与偏好设置。

## 🚀 编译与运行

### 系统要求
- macOS 14.0 (Sonoma) 或更高版本
- Xcode 15.0+ / Swift 5.9+

### 构建步骤
```bash
# 克隆仓库
git clone git@github.com:shuifa/KeyGrow.git
cd KeyGrow

# 打开 Xcode 工程
open KeyGlow.xcodeproj
```
或者直接使用命令行构建：
```bash
xcodebuild -project KeyGlow.xcodeproj -scheme KeyGlow -destination 'platform=macOS' build
```

## 🔐 辅助功能权限说明

由于需要全局捕获快捷键，KeyGlow 首次运行时需要授予 **辅助功能权限（Accessibility）**：
1. 启动 KeyGlow，若尚未授权将自动弹出偏好设置。
2. 点击 **「去授权」** 按钮，系统将自动打开 **「系统设置 -> 隐私与安全性 -> 辅助功能」**。
3. 勾选 **KeyGlow** 即可立即开始使用。
